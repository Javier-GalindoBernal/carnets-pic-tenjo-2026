## Fotografías

Para añadir la fotografía de una persona, suba el archivo a `fotos/` con el nombre
de su código (por ejemplo `fotos/ID-PIC-001-2026.jpg`) y cambie `foto=False` por
`foto=True` en la página correspondiente.

## Dar de baja un carné

Edite la página de la persona y cambie el campo **Estado** de `Activo` a `Inactivo`.
El QR impreso sigue funcionando y mostrará el nuevo estado.
